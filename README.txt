קניות בסופר משפחת שרון - גרסה 5.3

שינויים בגרסה זו:
1. לחיצה על כוכב למוצר מבקשת כמות קבועה לרשימת הבית.
2. הכמות הקבועה נשמרת ב-Firebase תחת המועדפים.
3. כפתור "הוסף את כל רשימת הבית לקניות" מוסיף את המועדפים לרשימת הקניות עם הכמות הקבועה.
4. תוקן המעבר ללשונית "רשימת הבית" - כניסה ללשונית לא מוסיפה אוטומטית מוצרים לקניות.
5. נשמרו החיפוש, הקטגוריות ומאגר המוצרים מהגרסה הקודמת.
